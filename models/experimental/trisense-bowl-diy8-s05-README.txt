TriSense bowl S05 — hub + 3 flower petals (diy8)

Print: hub + petal-a (jack) + petal-b + petal-c

Assembly:
  1. Lay hub flat (TriFlex pocket up).
  2. Seat hub tabs into open pockets in each petal floor (6×) — M3 from above.
  3. Bring petal butt faces together (same floor height — no stacking).
  4. Horizontal M3 through facing pads at each seam; optional glue in the gap.
  5. Petal-a faces the shell jack hole.
